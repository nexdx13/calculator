# آلة حاسبة بسيطة 🧮

أول مشروع لي لتعلم **GitHub** و **Python** من الصفر.

## ما هذا المشروع؟
برنامج آلة حاسبة يعمل على Windows 10، له **نافذة بأزرار** مثل الآلة الحاسبة العادية.

## ماذا تفعل؟
- أزرار الأرقام من 0 إلى 9.
- العمليات: الجمع `+`، الطرح `-`، الضرب `*`، القسمة `/`.
- زر `=` لحساب النتيجة.
- زر `C` لمسح الشاشة.
- عند القسمة على صفر تظهر رسالة "خطأ".

## كيف تشغّل البرنامج؟
1. تأكد أن Python مثبت على جهازك (الإصدار 3.10 أو أحدث).
2. افتح نافذة الأوامر (Command Prompt أو PowerShell) داخل مجلد المشروع.
3. اكتب الأمر التالي واضغط Enter:

```
python calculator.py
```

ستظهر لك نافذة الآلة الحاسبة، اضغط على الأزرار بالفأرة.

## الأدوات المستخدمة
- **Python** — لغة البرمجة.
- **tkinter** — مكتبة صنع النوافذ (تأتي مع Python).

## ما الذي تعلمته؟
- كتابة برنامج Python بسيط.
- صنع نافذة بأزرار.
- أوامر Git الأساسية: `init` و `add` و `commit` و `push`.
- رفع مشروع إلى GitHub.
